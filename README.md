# ElimuX Frontend (Next.js)

ElimuX is a unified education management platform for African schools.  
This repository contains the full modular frontend architecture built with:

- Next.js 14 (App Router)
- TailwindCSS
- Modular Bundles (1–12)
- API-driven architecture
- Scalable dashboard layout

## 📦 Bundles Overview

Each bundle represents a self-contained module:

1. Base App Structure  
2. UI Components  
3. API + Lib Utilities  
4. Auth Module  
5. Dashboard Shell  
6. Students Module  
7. Teachers Module  
8. Classes Module  
9. Finance Module  
10. Settings Module  
11. Global Providers + Middleware  
12. Final Cleanup + Validation
